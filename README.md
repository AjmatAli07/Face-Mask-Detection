# Face Mask Detection using PyTorch

A real-time Face Mask Detection system built using PyTorch, CNN, and OpenCV. The model detects whether a person is wearing a face mask through webcam input.

## Features

- Real-time webcam detection
- CNN-based classification
- Face detection using OpenCV
- Confidence score display
- Low-light handling improvements
- Data augmentation support

## Technologies Used

- Python
- PyTorch
- OpenCV
- NumPy
- Pillow
- TorchVision

## Project Structure

```text
Face-Mask-Detection/

```

## Installation

```bash

```

```bash
python train.py
```

## Run Detection

